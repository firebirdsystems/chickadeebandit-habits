# Habits

A [Chickadee Bandit](https://chickadeebandit.com/app-library/habits) app.

Build lasting habits with flexible frequency, grace days, and pause support. Daily, weekday, or X-per-week goals that forgive occasional misses so you keep going.

## Features

- Daily, weekday, or X-per-week frequency.
- Grace days that forgive an occasional miss.
- Pause a habit and resume it later.
- Personal habits inside the household hub.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-habits/releases/latest/download/bundle.json
```
